# Perfect Pickup (Next.js)

Pixel-perfect Next.js conversion of the Perfect Pickup Stitch HTML designs. Visual design, markup, colors, typography, and spacing match the original screens — only the framework changed.

## Screens

| Route | Screen |
|-------|--------|
| `/` | Home |
| `/login` | Login / Sign Up |
| `/restaurants` | Restaurants listing |
| `/menu` | Restaurant menu |
| `/checkout` | Checkout |
| `/track-order` | Live order tracking |
| `/profile` | My profile |

## Run

```bash
cd perfect-pickup-next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React 19
- Tailwind CSS v4 (same design tokens as the Stitch HTML config)
- Bebas Neue + DM Sans + Material Symbols Outlined
